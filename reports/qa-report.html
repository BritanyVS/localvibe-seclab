Dónde frontend/components/SearchNotice.tsx:11

Qué pasa Unsanitized input from the document location flows into innerHTML, where it is used to dynamically construct the HTML page on client side. This may result in a DOM Based Cross-Site Scripting attack (DOMXSS).

Por qué el test no lo ve Los tests comprobaban que el término aparece en pantalla, no que el navegador lo trate como texto. Con un payload en ?q= el test sigue en verde mientras el HTML se ejecuta.
